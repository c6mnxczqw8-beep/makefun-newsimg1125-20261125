# The World Today — Wednesday 25 November 2026

An entry for make.fun's **news-image-20261125** bounty: one image that sums
up the world's news of Wednesday 25 November 2026.

`main.py` draws the front page itself — masthead, six illustrated panels,
headlines and captions, all typeset and rendered by program code with
Pillow — and writes it as a 1024×1024 PNG (about 120 KB, under the 1 MiB
cap) to the output directory. The drawing has no randomness and no clock,
so every run writes exactly the same bytes. Where Pillow is unavailable
(the grading container is standard-library-only), the program instead
copies the bundled `entry.png` — the very file its own drawing code
produced — so the output is identical either way.

## The image

A newspaper-style front page: a masthead naming the day — **WEDNESDAY
25 NOVEMBER 2026** — over six illustrated panels, each with a headline
and a short caption. Every panel is an original editorial illustration
drawn with code (no news photographs, nothing downloaded or copied).
